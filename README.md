# MyInvestor

Repositorio maestro del proyecto MyInvestor.

## Documentos principales

- `MyInvestor_Cartera_y_Listas.md` — fuente operativa maestra para cartera, prioritarios, segunda línea y emergentes.
- `MyInvestor_Valoraciones.md` — histórico/registro de valoraciones.
- `MyInvestor_Sistema_Valoracion.md` — metodología y sistema de scoring MyInvestor.
- `Instrucciones_Proyecto_MyInvestor.md` — instrucciones generales del proyecto.

## Regla de mantenimiento

Git conserva el historial. No crear copias versionadas del tipo `v1.03`, `(1)`, etc. Actualizar siempre el fichero maestro correspondiente y registrar los cambios mediante commits.

Para `MyInvestor_Cartera_y_Listas.md`, actualizar solo cuando exista una compra/venta, cambio explícito de prioridad, valoración final, cambio material de tesis, cambio de asimetría por precio o incorporación/descarte explícito.
